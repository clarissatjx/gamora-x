# PS3 submission packaging — exact schemas and layout

A submission that errors out, or has the wrong schema/naming, scores **zero** for that
subsystem (Section 5.1 of the top-level spec) — schema correctness is not a minor detail here.
Validate every prediction file against this table before zipping.

## Per-subsystem `*_predictions.csv` schema (exact column names, no extras except where noted)

| File | Rows | Columns |
|---|---|---|
| `door_predictions.csv` | one per **predicted segment** (not per file — Test is one stream) | `start_time`, `end_time`, `prediction` ∈ {`Normal`, `Abnormal resistance`}. **No `file_id`.** Optional extra `confidence` column is fine, unused for scoring. |
| `acv_predictions.csv` | one per file | `file_id`, `ranked_cars` (`\|`-joined car IDs, most-to-least likely, **exact header ID** e.g. `03`). **No `prediction` column.** |
| `rail_predictions.csv` | one per file | `file_id`, `prediction` ∈ {`Normal`, `Side I`, `Side II`} |
| `shm_predictions.csv` | one per file | `file_id`, `prediction` (numeric damage value) |

`file_id` = source file name **including its extension** (e.g. `Test1.csv`, `acv_test_case.xlsx`).

## Validation checklist before zipping (script this, don't eyeball it)
- [ ] Column names match exactly (case-sensitive), no extra required columns missing
- [ ] Door: no `file_id` column present; every row has `end_time` > `start_time`
- [ ] ACV: `ranked_cars` for each file contains **every** car ID from that file's own headers,
      exactly once each, pipe-separated, using the file's native ID format (`03`, not `Car 3`
      or `3`)
- [ ] Rail/SHM/Door: `prediction` values are from the exact allowed label set (no typos like
      `abnormal resistance` lowercase, or `SideI` without the space)
- [ ] No missing rows for any file/segment you intend to be scored on — a missing row scores 0
      for that item, same as a wrong prediction
- [ ] Predictions were generated by running the **actual held-out test input files** through the
      app (Section 4.1 item 3) — not through a separate ad-hoc script, since the app is the
      evidence a real pipeline produced them

## Zip and folder layout
```
predictions.zip                 # flat: only the *_predictions.csv for subsystems attempted,
                                 # NO subfolders inside the zip, NO files for skipped subsystems
<Team Name>/                    # exact registered team name
├── demo_video.<ext>
├── predictions.zip
├── app/
└── Optional_Items/
    ├── write_up.<ext>
    └── <Subsystem>/{code/,model/}   # only for subsystems attempted
```
Do not include `04_Example_Submission/` or any raw dataset files in the submission.
